# Crest Homebrew tap

[Crest](https://crestnotch.app) puts the MacBook notch to work: music, calendar,
todos, system stats, and coding-agent approvals, one hover away.

```sh
brew install --cask zack40x/crest/crest
```

Updates arrive through the app itself (Sparkle); Homebrew's `auto_updates` flag
tells brew to stay out of the way. macOS 14 or newer.
